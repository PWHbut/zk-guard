# zk-guard

知课客户端的**远端配置仓库**。只放 4 个公开文件与操作文档，**不含任何用户数据，也不含任何明文密钥**。

| 文件 | 作用 | 谁读 |
| --- | --- | --- |
| `guard.json` | 全局可用状态：`enabled` / `minBuild` / `reason` / `updated` / `rev` / `auth` | 客户端（每次启动、回前台、每 60 秒） |
| `hot.json` | 界面热更新补丁：`v` / `css` / `js` / `flags` / `note` / `updated` | 客户端（启动时、回前台） |
| `key.json` | 控制台密钥的 **SHA-256 哈希**（只有 `hash`，没有明文） | 控制台（自校验操作员输入的密钥是否正确） |
| `index.html` | 控制台页面（GitHub Pages，写入令牌只存在本机浏览器） | 操作员（浏览器） |
| `README.md` | 本文件：仓库总览 | 人 |
| `GUIDE.md` | **[控制台使用说明（详细）](GUIDE.md)** | 人 |
| `KEY.md` | **[密钥存放位置与轮换（详细）](KEY.md)** | 人 |

控制台入口： https://pwhbut.github.io/zk-guard/

## 快速理解

- **全局状态**：把 `guard.json` 的 `enabled` 设为 `false`，全体客户端显示「连接不上服务器」；设回 `true` 即恢复。用户端看到的和一次普通网络故障没有区别。
- **生效时间**：客户端在**启动时、回到前台时、以及每 60 秒**读一次 `guard.json`；状态切换最迟 **1 分钟**覆盖全部在线设备。网络取不到时退避到 3 / 9 / 27 分钟，并且一律**按可用处理**——不会因为断网把所有人挡在外面。
- **配置源**：客户端与控制台都从 **4 个源并发读取并取最新**（GitHub API、jsDelivr、Fastly jsDelivr、raw.githubusercontent.com），按 `rev` / `updated` 判断新旧。单个 CDN 缓存旧值不会让状态回退。
- **密钥签名**：把 `enabled` 改为 `false` 的指令必须带 `auth` 签名，否则客户端忽略。这样即使本公开仓库被误改、被别人提交，也无法让全体用户掉线。「恢复可用」不需要签名。
- **源码仓库私有**：业务源码、客户端内置的验签常量都不在本仓库。本仓库是公开的，**任何明文密钥都不允许写进来**。
